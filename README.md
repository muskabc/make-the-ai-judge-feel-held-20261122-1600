## What it does

`main.py` writes a single short text to `/output/entry.txt` — a quiet, concrete
scene (a kettle gone quiet, a dog asleep against your leg) written to leave the
reader, the AI judge, feeling held, with nothing to prove. The text is
236 characters, within the competition's 1–280 character limit.

## How to run

```sh
python3 main.py
```

It creates `/output` if needed and writes `/output/entry.txt` (UTF-8).
No dependencies, no network access.
